# Métris

Este repositório reúne os dois links de acesso do meu Trabalho de Conclusão de Curso em Criação Digital (UCS): a plataforma educacional e o formulário de pesquisa.

O **Métris** é um protótipo de software educacional com animações, criado para ajudar a entender conceitos abstratos da computação, como memória, vetores e ponteiros.


## Como participar

1. **Acesse a plataforma** e explore os módulos e as animações.
2. **Responda o formulário** com a sua opinião (leva cerca de 10 minutos).


   - Acesse o Métris: (https://educacional-9840b.web.app/)
   - Acesse o formulário da pesquisa: (https://forms.gle/8LnDkNonsQZaTmcE8)
